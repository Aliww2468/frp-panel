# FRP 本地面板

双击根目录的 `启动面板.cmd`，打开 http://127.0.0.1:17600 。启动器复用已启动的面板。

界面包含网络概览、TCP / UDP 代理规则、最近 100 行运行日志、可编辑的连接配置。支持搜索、协议筛选、复制公网地址、新建 / 编辑 / 删除规则、日志导出和客户端启动 / 停止。

在「连接配置」填写服务器 IP / 域名、控制端口、Token、用户标识和 TLS / 线路协议，保存后添加代理规则，再启动客户端。已有 Token 不回显，可保留、替换或清除。后台刷新不会覆盖尚未保存的表单内容。修改服务器配置前需要先停止客户端。

也可点击「导入配置文件」，选择 UTF-8 编码的 FRPC `.toml` 文件（最大 256 KB）。先校验并预览服务器和规则数量，确认后替换连接、认证与全部代理规则，当前配置自动备份。导入不会自动启动客户端；运行中必须先停止。导入时保留本机管理接口及日志位置，文件中的其他高级配置一并保留。`includes` 多文件配置需先合并；Token、证书等引用文件应事先放在正确位置，相对路径以项目 `client/` 为基准。暂不支持旧版 INI、YAML 或 JSON 格式。

「重置连接与代理」会清空服务器地址、认证信息与代理规则，并使用新的日志文件。旧配置自动备份，旧日志和旧令牌文件保留在本机但不再被重置后的配置引用。空白状态下不能启动客户端；面板提供“添加连接配置”入口。

## 运行

需要 Python 3.11+，不需要安装第三方依赖。启动器优先使用本机 Codex 自带 Python，然后查找 PATH 中的 Python。

```powershell
python panel/server.py
```

面板绑定 `127.0.0.1:17600`，从 `client/frpc.toml` 读取配置，通过本机 FRPC 管理接口读取真实代理状态。FRP 密码和令牌只在后端读取。启动面板本身不会启动 FRPC；点击“启动客户端”才会建立公网转发。

关闭网页不会停止面板或客户端。需要停止转发时，在概览点击“停止客户端”。面板启动的 FRPC 在后台运行。手动运行 `server.py` 时，可用 Ctrl+C 停止面板进程，FRPC 独立运行。

## 配置保护

- 写入前解析 TOML 并调用本地 `frpc.exe verify` 校验，通过后原子替换配置。
- 原配置保存在 `panel/backups/`，备份包含原始凭据，仅供本机恢复，不应公开上传。
- 编辑时保留全局设置和代理高级字段，并通过版本校验防止覆盖外部修改。连接配置保存会规范化 TOML 格式，原注释保留在备份中。
- 客户端在线时自动请求热重载。热重载失败会提示，保存的配置留待下次启动生效。
- 面板当前编辑 TCP / UDP 基础字段；FRPS 配置、云端防火墙与安全组仍需单独设置。
- “运行中”表示 FRPC 报告代理已注册，不能替代玩家从外网实际进服测试；不提供模拟流量统计。

管理接口参考：[FRP 官方客户端文档](https://gofrp.org/zh-cn/docs/features/common/client/)。
