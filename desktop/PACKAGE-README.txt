FRP Panel / Windows x64

双击安装包完成安装，再从桌面或开始菜单打开 FRP Panel。
首次使用：连接配置 > 导入配置文件，选择服务商提供的 frpc.toml。
右上角“外观”可以选择简约浅色、午夜深色、暖砂米色、雾蓝灰，选择会自动保存。
安装包不含任何个人服务器地址、Token 或代理规则。

关闭窗口会隐藏到托盘。右键托盘可退出软件并停止转发。
同一 Windows 会话只允许一个面板运行，跨安装目录也会检测。重复启动会提示软件已在运行并取消本次启动；请双击托盘图标打开原窗口。
安装更新或卸载前，请先从托盘退出软件。
开机自启默认关闭，可以在托盘菜单中开启。

已内置 Python 3.12 和 FRPC 0.71.0。
安装时自动检测 .NET 8 Desktop Runtime x64 和 WebView2，已有则跳过，缺少则从 Microsoft 联网安装。
安装 .NET 会请求 Windows 管理员权限；取消或安装失败时可重试，不会继续安装缺少运行环境的应用。
支持 Windows 10/11 x64；离线安装需事先安装这两项运行环境。

配置：安装目录/client/frpc.toml
日志：安装目录/client/logs
备份：安装目录/panel/backups
更新不会覆盖已有配置，并会清理旧版内置 .NET 文件；卸载保留生成的配置、日志及备份，不移除系统共享运行环境。
软件默认占用本机 17600 端口；请勿同时运行其他目录下的旧版面板。

第三方许可见 licenses 文件夹和运行环境自带的许可文件。
