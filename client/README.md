# FRPC 客户端运行目录说明

本目录用于存放 FRPC 可执行文件、当前配置及运行数据。安装版已附带 FRPC；从源码运行时需要自行准备。项目当前配套版本为 **FRPC 0.71.0 Windows AMD64**。

## 1. 从源码准备客户端

从 [FRP 0.71.0 官方发行页](https://github.com/fatedier/frp/releases/tag/v0.71.0) 下载 Windows AMD64 压缩包，并依据该发行页提供的摘要校验文件完整性。解压后保留项目根目录中的 `frp_0.71.0_windows_amd64` 文件夹，用于安装包构建时读取第三方许可证。

在项目根目录运行：

```powershell
Copy-Item -LiteralPath ./frp_0.71.0_windows_amd64/frpc.exe -Destination ./client/frpc.exe
```

替换正在使用的 FRPC 前，应停止客户端并退出面板。界面中的 FRPC 版本标签目前按配套版本显示，不会自动检测手工替换后的二进制版本；自行更换 FRPC 时，应另外核对兼容性。

## 2. 文件用途

| 路径 | 用途 |
| --- | --- |
| `frpc.exe` | FRP 客户端程序 |
| `frpc.toml` | 面板读取和修改的当前配置 |
| `logs/frpc.log` | 新配置默认的 FRPC 日志文件；重置或自定义配置后可能采用其他文件名 |
| `logs/panel-launch.log` | 通过面板启动 FRPC 时记录的标准输出和错误输出 |
| 用户准备的令牌或证书文件 | 供 TOML 中的外部文件引用使用，不随导入操作自动复制 |

首次启动面板时，如果 `frpc.toml` 不存在，会生成空白服务器配置及随机本机管理密码。存在的配置不会自动覆盖。配置备份保存到上级的 `panel/backups/`，而不是本目录。

## 3. 手工校验配置

在项目根目录打开 PowerShell，以 `client` 为工作目录执行校验，保证外部文件相对路径与实际运行一致：

```powershell
Push-Location ./client
try {
    ./frpc.exe verify -c ./frpc.toml
} finally {
    Pop-Location
}
```

`verify` 校验配置，不启动转发。校验成功不代表服务器认证、端口权限、本地业务或公网链路已通过测试。错误输出可能引用配置内容，对外分享前应检查凭据。

## 4. 配置、备份与迁移

正常使用时通过面板修改或导入配置。手工编辑前先停止客户端、退出面板并备份原文件。外部文件的相对路径以本目录为基准；迁移到其他计算机后需要检查绝对路径及外部依赖。

恢复步骤见 [用户操作手册](../docs/user-guide.md#8-数据目录备份与恢复)，导入限制见 [配置导入说明](../docs/user-guide.md#32-导入-toml-文件)。

## 5. 版本控制边界

本目录仅将这份说明提交到 Git。可执行文件、个人配置、密码、令牌、证书、临时校验文件和日志均属于本机运行数据。不要通过强制添加绕过忽略规则，也不要将完整客户端目录上传到公开问题反馈或发行附件。
