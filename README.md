# FRP Panel

FRP Panel 是面向 Windows 的 FRP 客户端可视化管理软件，提供配置导入、TCP/UDP 代理管理、运行日志、系统托盘、单实例检测及手动在线更新。桌面采用 .NET 8 WinForms 与 WebView2，本机后台采用 Python 标准库，实际转发由 FRPC 执行。

当前文档适用于 **FRP Panel 1.3.0**，发行包附带 **FRPC 0.71.0**。两个版本号分别代表面板软件和转发客户端。

## 下载与首次使用

从 [最新正式发行页](https://github.com/Aliww2468/frp-panel/releases/latest) 下载安装程序及对应 SHA-256 文件。1.3.0 安装程序为 `FRP-Panel-Setup-1.3.0-x64.exe`。

1. 安装前先从托盘退出正在运行的旧版面板。
2. 运行安装程序。支持 Windows 10/11 x64，内置 Python 与 FRPC；缺少 .NET 8 Desktop Runtime x64 或 WebView2 时自动检测并联网补装。
3. 启动软件，在“连接配置”中导入服务商提供的 UTF-8 `.toml` 文件，或手工填写连接信息。
4. 核对代理规则，确认本地业务已启动，再点击“启动客户端”。
5. 检查代理状态与日志，并从外部网络验证实际访问。

安装包不包含个人连接信息。软件启动、开机自启动和配置导入均不会自动建立转发。多数服务商要求先在其后台创建隧道，面板中的“新建代理”只修改本机配置。

## 功能范围

- 查看客户端与代理的实际管理接口状态，搜索及筛选代理，复制 TCP/UDP 访问地址。
- 新建、编辑和删除 TCP/UDP 基础规则；已有高级设置在支持的操作范围内保留。
- 导入单个 TOML 文件，预览并校验后替换连接及规则，同时保留本机管理和日志设置。
- 保存前校验配置，保留原文件备份，并检查配置版本以避免覆盖外部修改。
- 查看和导出最近日志；完整历史记录保存在实际日志文件中。
- 关闭或最小化窗口后驻留托盘，通过托盘恢复窗口、启停客户端、设置自启动或退出。
- 同一 Windows 会话只允许一个桌面实例，重复启动提示后取消本次启动。
- 提供简约浅色、午夜深色、暖砂米色、雾蓝灰四种主题；Windows 11 标题栏同步颜色。
- 从本项目 GitHub Releases 手动检查正式更新，下载并校验后，由用户确认安装。

本软件管理本机 FRPC，不代替 FRPS 服务端配置、服务商隧道申请、本地业务启动或防火墙设置。客户端“运行中”表示管理接口可读；实际转发应结合代理状态及外网业务测试确认。

## 源码运行入口

在项目根目录操作。桌面构建需要 .NET 8 SDK，运行需要 .NET 8 Desktop Runtime x64 和 WebView2；独立网页后台需要 Python 3.11 或更新版本。

先按 [客户端目录说明](client/README.md) 准备 FRPC 0.71.0，再构建桌面版：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./desktop/build.ps1
```

构建后使用项目根目录生成的“FRP 面板.lnk”或“启动软件.cmd”。构建产物为完整目录，不能只复制其中的 EXE。

单独运行网页后台：

```powershell
python ./panel/server.py
```

随后访问 `http://127.0.0.1:17600`。首次启动仅在配置不存在时创建空白配置。退出独立网页模式的方法见 [后台运行说明](panel/README.md)。

## 配置与数据

默认配置为 `client/frpc.toml`，默认日志位于 `client/logs/`，配置备份位于 `panel/backups/`。桌面缓存及更新下载位于 `%LOCALAPPDATA%/FrpPanel/<目录标识>/`。

配置、外部 Token 文件、证书、日志和备份可能包含凭据，不应提交到公开仓库。发行包采用文件白名单构建，不包含开发目录的个人配置。完整数据说明见 [用户手册](docs/user-guide.md#8-数据目录备份与恢复)。

## 第三方组件

本项目是独立的 FRP 管理界面。转发组件来自 [fatedier/frp](https://github.com/fatedier/frp)，其他主要依赖为 Microsoft .NET、Microsoft WebView2 和 Python。第三方组件适用各自许可证；发行目录的 `licenses/` 与运行环境目录保留相应许可文件。不得将本项目文档视为对第三方组件的重新授权。
